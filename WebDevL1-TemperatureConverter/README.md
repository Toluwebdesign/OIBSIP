# Temperature Converter

A responsive temperature converter built with HTML, CSS and vanilla JavaScript as part of the OIBSIP internship tasks.

## Features
- Convert between Celsius, Fahrenheit and Kelvin.
- Display all three units simultaneously.
- Validate empty and invalid numeric input.
- Reject values below absolute zero.
- Responsive desktop and mobile layout.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the Live Server extension.

## Conversion Formulas
- Celsius to Fahrenheit: `(°C × 9/5) + 32`
- Fahrenheit to Celsius: `(°F − 32) × 5/9`
- Celsius to Kelvin: `°C + 273.15`
- Kelvin to Celsius: `K − 273.15`
