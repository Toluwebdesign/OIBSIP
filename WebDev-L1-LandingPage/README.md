
# Planora – Student Productivity Landing Page

## About the Project
Planora is a static landing page for a student productivity platform designed to help students organise their assignments, plan study sessions, and track their daily goals.

The website introduces the platform and highlights its features through a clean, simple, and user-friendly design.

## Features
- Sticky navigation bar with section links.
- Hero section with a headline, description, and call-to-action button.
- Features section highlighting three main services.
- About section introducing the brand.
- Contact call-to-action section.
- Footer with contact and social links.
- Responsive layout for desktop and mobile screens.
- Consistent colour palette and typography.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
